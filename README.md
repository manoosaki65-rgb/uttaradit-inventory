# uttaradit-inventory — Local

> สถานะล่าสุด: ดู LOCAL-QA-REPORT.md วันที่รับปัจจุบันอ่านจากข้อมูลในไฟล์ตามคำสั่งล่าสุด ไม่อ่านจากชื่อไฟล์แล้ว ข้อความเรื่องชื่อไฟล์ด้านล่างเป็นขั้นตอนก่อนการแก้ล่าสุด การทดสอบ UI/print engine ยังไม่ครบและการลบยังไม่มี owner auth บน Local

ใช้ source Inventory Final v77 ที่กู้ได้จริง รักษาหน้าหลัก เมนู ช่องค้นหา ตัวกรอง คอลัมน์ และ CSS เดิม ยังไม่ Import Master 4,107 รายการ ไม่แก้/ลบ/Deploy AppDeploy เดิม

## รัน

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

เปิด http://127.0.0.1:5173/ ข้อมูลเก็บใน localStorage ของ browser นี้ ยังไม่ใช่ฐานข้อมูลร่วมหลายเครื่อง อย่าล้าง storage หากต้องการเก็บข้อมูล Local ต่อ

http://127.0.0.1:5173/?local-test=1 ใช้ข้อมูลทดสอบแยกจากทะเบียนหลัก มีรายวัน 47 รายการและปีแหล่งเงิน 69 ที่เลือกเพื่อทดสอบหน้าพิมพ์เท่านั้น ไม่ใช่การรับรองปีแหล่งเงินของข้อมูลจริง

## ใช้งานสามฟังก์ชัน

1. นำเข้าข้อมูล: เลือก Excel .xls/.xlsx หนึ่งไฟล์ หรือ PDF หนึ่งไฟล์ หรือทั้งคู่วันเดียวกัน ชื่อต้องมีวันที่ พ.ศ. YYMMDD เช่น Report 690910.xls กดปุ่มเดิม “อัปเดต Master”; บน Local ปุ่มนี้อัปเดตทะเบียนรายวัน ไม่โหลด Master 4,107 รายการ อ่านไม่เกิน 1,000 รายการ PDF ต้องมีข้อความและใช้คอลัมน์เดิม ไม่รองรับภาพสแกน
2. พรีวิว / พิมพ์รายงาน: เลือกปีแหล่งเงินให้ครบ กรองวันที่รับ เดือน ปี หรือคอลัมน์ตามต้องการ กดพรีวิว แล้ว “พิมพ์รายงาน” ภายในพรีวิว รายงานใช้รายการตามตัวกรองเช่น source เดิม จึงต้องกรองวันรับเองเมื่อต้องการหนึ่งวัน
3. เลือกช่วงวันที่ / พิมพ์ย้อนหลัง: เลือกวันที่รับหรือวันที่หน่วยงานคีย์ กำหนดวันเริ่ม/สิ้นสุด แล้วพรีวิว รวมวันต้นปลายและอ่านทะเบียน Local ทั้งหมด ไม่ใช้ตัวกรองหน้าหลักตามเดิม ปิดพรีวิวเพื่อกลับตัวกรองเดิม

รายงานใช้ JSX/CSS เดิม: A4 แนวนอน ขอบ 5 mm, 25 รายการต่อส่วน, 13 คอลัมน์ ยอดรวมและผู้ส่ง/ผู้รับเดิม เพิ่มเฉพาะกรอบพรีวิวและคำสั่งเปิด browser print

## ตรวจซ้ำ

```powershell
node scripts/test-local.mjs
npx tsc --noEmit
npm run build
```

test-local อ่านไฟล์รายวันจริงใน Downloads และใช้ storage จำลอง ไม่เขียนทะเบียนหลัก ผลอยู่ audit/local-results.json; scripts/audit-original.mjs ตรวจพฤติกรรมและ bug ต้นฉบับ

- original/v77/: ต้นฉบับ 15 ไฟล์ ไม่แก้; checksum audit/source-sha256.json
- LOGIC-AUDIT.md: พฤติกรรมต้นฉบับ
- LOCAL-RECOVERY-REPORT.md: ส่วนที่ใช้เดิม/เพิ่ม และผลตรวจล่าสุด
- audit/local-daily-preview.jpg และ audit/local-keyed-preview.jpg: ภาพพรีวิวจริงบน Local

นำเข้า กรอง พรีวิวรายวันและย้อนหลังทดสอบบน browser จริงแล้ว คำสั่งพิมพ์เรียก browser print แต่เครื่องมือควบคุมติดรอหน้าต่างพิมพ์ จึงยังไม่ยืนยัน PDF จาก print engine หรือกระดาษจริง ต้องตรวจส่วนนี้ก่อนใช้รายงานจริง หยุดก่อน Import Master และ Deploy ตามคำสั่งผู้ใช้
